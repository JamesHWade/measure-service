# Retention qualification references and attribution

These frozen reference values make the installed offline qualification command
reproducible. Their SHA256 digests identify reviewed data inputs, not versions
required of the production Python, Torch or R environment. The production
calculator uses the standard library and does not import the reference engines.

## Source-law reference

`retention-law-upstream-v1.json` contains derived retention-factor values at 21
compositions for each of three conditionally selected laws and 500 parameter
records from:

Mohammad Haddadnia, Malcolm Sim, Han Hao, Kazuhiro Hotta, Martin Seifrid, Dennis
Fedotov, Tony C Wu, Shi Xuan Leong, Felix Strieth-Kalthoff and Alan
Aspuru-Guzik (2026), *MoSeS Enables Autonomous Chromatography Operation through
Programmable Analytical Expertise*, Zenodo,
[DOI 10.5281/zenodo.22109729](https://doi.org/10.5281/zenodo.22109729).

The [official record API](https://zenodo.org/api/records/22109729) declares the
author dataset [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), verified
2026-10-28. These derived reference values are supplied with that attribution
under CC BY 4.0. Changes from the source data are the calculation of conditional
`k(phi)` values, addition of input/source hashes and reference-engine metadata,
and omission of the original coefficients and chromatograms. The archive SHA256
is `880533ded926f766ce9504d4f164e9c5195b775e40061c18d70ae79497f03f71`.

The values were generated by the inspected upstream model classes using
`torch.float64`. The file records the exact scientific source identity and
reference runtime. No upstream implementation files are redistributed here.
The source's natural-log signs and mathematical conventions are documented in
[the qualification note](../../../../docs/retention-model-qualification.md).

Reference SHA256:
`92a43a7fbfa148d8d25d99506c9202ca4c3ad435c1c233cc70cb51a18167eb30`.

## Independent ideal-retention reference

`retention-ideal-binary64-v3.json` contains 18 synthetic cases created for this
project, evaluated independently with 70-digit mpmath quadrature and bracketed
root solving. Inputs retain decimal strings, exact parsed binary64 rationals
and hexadecimal representations. The reference includes a decimal-rounding
counterexample and a separate binary-exact inclusive endpoint. This synthetic
reference is supplied under the repository's MIT license.

Reference SHA256:
`7ecd483f1a0ca5e2ee75e7a4f19940e7288a8199b164d90d58202d2b2770d02d`.

## Review boundary

The references identify fixed numerical comparisons. Regenerating them with a
different source or reference runtime can change values or metadata and hence
their byte digests. Review a replacement as a separately identified reference;
production dependency revisions need not be pinned to a reference generator.
Neither reference establishes original archive model assignment, fitted
physical parameters, signal or hardware qualification, or fresh optimizer
performance.
